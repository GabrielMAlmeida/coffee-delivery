# React + Vite

☕ Coffee Delivery

Projeto de um e-commerce simples para uma cafeteria fictícia, focado em demonstrar o uso de gerenciamento de estado com a Context API do React.

Este projeto é uma aplicação web que simula um cardápio de cafés onde o usuário pode selecionar produtos, adicioná-los ao carrinho, preencher um formulário de checkout e finalizar um pedido.

✨ Funcionalidades

Listagem de Produtos: Visualização dos cafés disponíveis para compra, carregados de um "banco de dados" local.

Gestão de Carrinho:

Adicionar cafés ao carrinho.

Aumentar ou diminuir a quantidade de cada item.

Remover itens do carrinho.

Limpar o carrinho após a finalização da compra.

Atualização em Tempo Real: O ícone do carrinho no cabeçalho (Header) é atualizado automaticamente com a quantidade de itens.

Checkout: Formulário para o usuário preencher seus dados de endereço e pagamento.

Página de Sucesso: Após o envio do formulário, o usuário é redirecionado para uma página de confirmação.

🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

React.js: Biblioteca para a construção da interface de usuário.

Vite: Ferramenta de build e servidor de desenvolvimento rápido.

React Router DOM: Para gerenciamento das rotas da aplicação (Home, Checkout, Sucesso).

React Context API: Para o gerenciamento de estado global (o nosso carrinho de compras).

React Hook Form: Para a construção e validação do formulário de checkout.

Bootstrap: Framework CSS para estilização rápida e responsiva.

Lucide React: Para os ícones (carrinho, mais, menos, etc.).

📦 Como Rodar o Projeto

Para executar este projeto localmente, siga os passos abaixo:

1.Clone o repositório:

git clone [https://github.com/seu-usuario/coffee-delivery.git](https://github.com/seu-usuario/coffee-delivery.git)



2.Acesse a pasta do projeto:

cd coffee-delivery



3.Instale as dependências:

npm install



4.Execute a aplicação:

npm run dev



A aplicação estará disponível em http://localhost:5173 (ou em outra porta indicada no seu terminal).
